About AllStaff

● Implemented employee scheduling and attendance tracking with schedule-based clock-in and clock-out validation, along with automated weekly payroll calculations using recorded work hours and hourly rates.

● Developed employee management functionality using Spring Boot and Thymeleaf, allowing administrators to add new employees and manage employee records.

● Enabled administrators to update employee information, including job positions and hourly rates, and temporarily deactivate employee accounts.

● Built a PostgreSQL-backed time simulation system using the database as the authoritative time source, supporting accelerated time progression at 4× and 8× speeds.

● Secured administrative functionality with Spring Security and BCrypt password hashing to protect access and safeguard user credentials.
