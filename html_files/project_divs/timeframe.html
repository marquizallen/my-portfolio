About TimeFrame

● Developed social media features for creating text and image posts, liking and commenting on posts, and following other users.

● Designed and implemented a PostgreSQL database schema to manage users, posts, comments, likes, and social relationships.

● Built RESTful API endpoints using Spring Boot and JDBC to connect TypeScript frontend components with backend services and database operations.

● Implemented secure, session-based authentication using Spring Security, CSRF protection, and BCrypt password hashing.

● Integrated Cloudinary for image uploads and storage, enabling users to share image-based content within the application.
